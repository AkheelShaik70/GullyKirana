This is complete Frontend based project.
This project helps to connect Local Kirana stores with users along with delivery agent.
We have built this project completely using HTML,CSS and Javascript.
All the images, user details and any dynamic content is stored into Local Storages of browser.
User authentications are stored in Session storage of browser.
Project includes----(Vendor Portal(to add products and get orders), User Portal(to search vendors and place orders) and Delivery agent(to accept delivery order and get order details)
We implemented proper tracking system.

**Scope of Future Enhancement**
Since this is complete frontend, future enhancement may include proper backend and database integration alongside Restful APIs
Multiple future enhancements are planned and can be added.
